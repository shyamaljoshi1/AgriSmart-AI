# Smart Farm Mobile App (React Native)

A mobile application created in React Native for precision crop disease diagnosis and livestock telemetry monitoring.

## 📱 Features

1. **Disease Detection & Advisory Tab**:
   - Camera shutter button for leaf photo capture.
   - On-Device RAM DL model inference simulator.
   - Comprehensive agronomic disease advisory (Immediate, Chemical, Organic, Preventative).
   - Audio advisory voice player.

2. **Livestock Monitoring Tab**:
   - Vitals dashboard (Temperature, Heart Rate, Rumination, Activity).
   - Real-time alerts feed.
   - Add livestock & log vitals.

3. **Python Model Integration**:
   - Modularity built into `src/services/dlModelService.js`.
